# WWDC source inventory

Reviewed on 2026-10-08 using Sosumi CLI full transcripts and Apple's public Design video catalog. This is a topical sweep of interface writing, naming, personality, and related content design, rather than a search of every spoken word in WWDC history. The skill's patterns paraphrase the principles; its copy examples are original and require matching app behavior.

## Direct writing sessions

| Session | Distinct contribution |
| --- | --- |
| [Writing Great Alerts (2017)](https://developer.apple.com/videos/play/wwdc2017/813/) | Earn interruptions; state the event, explain reasons, and give precise recovery choices. Scan titles and actions independently. |
| [Writing for interfaces (2022)](https://developer.apple.com/videos/play/wwdc2022/10037/) | PACE: Purpose, Anticipation, Context, Empathy. Treat wording, hierarchy, and timing as interaction design. |
| [Add personality to your app through UX writing (2024)](https://developer.apple.com/videos/play/wwdc2024/10140/) | Derive voice from audience and purpose, turn traits into writing choices, and adapt tone by situation. Purposeful warmth can justify extra words. |
| [Make a big impact with small writing changes (2025)](https://developer.apple.com/videos/play/wwdc2025/404/) | Remove filler and duplicated meaning, preserve behavioral modifiers, lead with useful benefits, and maintain a concept-specific word list. |
| [Craft clear names for features and labels in your app (2026)](https://developer.apple.com/videos/play/wwdc2026/290/) | Think/feel/do; evaluate whether a name belongs, sets expectations, and works everywhere. Test real UI grammar and adverse states. |

## Related content-design sessions

| Session | Distinct contribution |

## Text-based events and boundaries

[Meet the Presenter: Writing for interfaces (2022)](https://developer.apple.com/videos/play/wwdc2022/110532/) and [Q&A: UX writing (2023)](https://developer.apple.com/videos/play/wwdc2023/111484/) are text-based events; Sosumi returned no transcript. Their public descriptions were reviewed. Apple's [2023 Q&A highlights](https://developer.apple.com/news/?id=5mcfho5g) supplement the sessions rather than substitute for a complete transcript.

Discovery excluded code and file writing, Writing Tools API integration, typography implementation, general localization implementation, incidental word mentions, keynote recaps, and non-WWDC talks. [The process of inclusive design (2021)](https://developer.apple.com/videos/play/wwdc2021/10304/) was excluded as general process advice; its companion practice session directly covers language and content. Historical component examples illustrate writing decisions; the implementation reference requires current documentation for present-day platform behavior.
