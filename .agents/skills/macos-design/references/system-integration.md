# System integration

## External entry points

Choose integrations by the content workflow: Spotlight for searchable content, Quick Look for previewable file types, the share menu for outgoing content, Services for applicable selection-based exchanges, and Shortcuts for repeatable app actions. Use AppleScript when the audience needs script automation. Each entry point resolves to the intended content, including when data is missing or has changed.

## File transfer and Dock

Drag/drop should preserve transferable representations and provide meaningful destination and failure feedback. The app icon and Dock menu should identify the app and expose useful quick actions or recent content, with badges reserved for meaningful outstanding information.

## Notifications

Notify for relevant events when people are elsewhere; reflect routine completion inline while they are working in the app. Keep notification content privacy-aware and open the appropriate destination when activated.
