# Entry points and lifecycle

## First use

Teach unfamiliar capabilities in context and make optional onboarding dismissible; its length follows the necessary learning, not a page quota. Launch UI previews the first usable screen without delaying access for branding.

## System entry points

Choose integrations by a concrete user task: widgets for glanceable updates and suitable quick actions, Live Activities for ongoing time-bounded events, App Shortcuts for repeatable tasks, Spotlight for discoverable content, and the system share sheet for transferable content. Each entry point should resolve to the relevant content and survive unavailable or changed data.

## Notifications and interruptions

Use notifications for events people need outside the app; expose the relevant action and notification settings. Preserve context on backgrounding; pause attention-dependent work while letting permitted background work continue. Audio interruptions need audio-session handling rather than a blanket pause on every scene-phase change.
