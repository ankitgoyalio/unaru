# Appearance

## Materials follow function

Use native navigation and toolbar components to adopt the current system design. On systems that support Liquid Glass, reserve it for the functional layer above content; ordinary cards and content surfaces use standard materials. Custom glass is selective, with the regular variant as the starting point and clear glass reserved for visually rich backgrounds where legibility holds. Remove older custom bar fills or overlays that obstruct system treatment.

Use semantic colors and text styles that adapt to the system. Check custom assets in light/dark appearance and increased contrast. Glass changes with content behind it: assess labels, icons, and boundaries over busy and sparse content as well as with Reduce Transparency. For custom rendering, respond to Bold Text and Reduce Motion while preserving essential state feedback. Scale SF Symbols with nearby text.

Sources: [Materials](https://developer.apple.com/design/human-interface-guidelines/materials), [Color](https://developer.apple.com/design/human-interface-guidelines/color), [Typography](https://developer.apple.com/design/human-interface-guidelines/typography), [SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols), [Dark Mode](https://developer.apple.com/design/human-interface-guidelines/dark-mode), [Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility), [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass).
