# Unaru

A SwiftUI application with a Vapor backend, a shared Swift package, and
KiteConnect integration.

- [Development setup](docs/development.md)
- [Documentation policy and build guides](Documentation/README.md)
- [Published documentation](https://ankitgoyalio.github.io/unaru/)
- [Contributing](CONTRIBUTING.md)
- [Security reporting](SECURITY.md)

Use Swift 6.4, Xcode 27.2, and SwiftFormat 0.64.5. Run
`python3 Scripts/check-development.py` before building.
